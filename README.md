# Colonias — laboratorio gráfico

[https://pacosanx.github.io/colonias-espora/](url)

Herramienta web para crear composiciones gráficas inspiradas en colonias de hongos, mohos y levaduras.

## Usar

Abrí la página publicada y usá los controles para generar composiciones, cambiar su estructura y formato, seleccionar y editar elementos, y exportar la pieza como PNG. También podés descargar y abrir estos archivos localmente.

## Tipografía

La herramienta puede usar **Clamofte Regular** si está instalada en el sistema. La versión demo que se usó en el prototipo está indicada por su autora para uso personal y no se incluye en este repositorio. [Consultar la fuente y su licencia](https://www.dafont.com/clamofte.font).
